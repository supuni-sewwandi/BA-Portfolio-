Cafe Management System - Business Analyst Portfolio

Welcome to my Business Analyst portfolio project! This repository contains a comprehensive set of BA artifacts designed for a *Digital Cafe Management System (CMS)*. It demonstrates my practical skills in requirements gathering, process modeling, agile documentation, and data analysis.

---

 📌 Project Overview
* *Domain:* Food & Beverage / Retail Tech
* *Problem Statement:* The current manual order-taking and paper-based billing lead to long customer wait times, order errors, and inefficient inventory tracking.
* *Objective:* To design a digital Cafe Management System that streamlines customer ordering (POS), automating communication with the kitchen, and provides real-time sales performance tracking for management.

---

 📑 Portfolio Artifacts & Documentation
 1. Requirements Documentation
* *Business Requirements Document (BRD):* Outlines the project scope, high-level business goals, stakeholder analysis, and success metrics.
* *Software Requirements Specification (SRS):* Detailed functional requirements (User Authentication, Order Placement, Bill Generation) and non-functional requirements.
* *Agile Product Backlog & User Stories:* Formatted as "As a [User Role], I want to [Action], so that [Benefit]" along with clear Acceptance Criteria.

2. Process Mapping & Visuals
* *As-Is vs. To-Be Process Flow:* Swimlane flowcharts showcasing the optimization of the cafe workflow.
* *Use Case Diagram:* Defines system boundaries and interactions between actors (Cashier, Customer, Manager, Kitchen Staff).
* *UI/UX Wireframes:* Low-fidelity mockups for the Cashier's Point-of-Sale (POS) dashboard.

 3. Data Analysis & SQL Scripts
* *Cafe_Analytics_Queries.sql:* Sample SQL scripts demonstrating how to query database tables to extract business insights like best-selling items and revenue.
